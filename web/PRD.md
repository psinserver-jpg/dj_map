# [PRD] 부산시 편의점 지도 웹 서비스 (Busan Convenience Store Map)

---

## 1. 프로젝트 개요 (Overview)

### 1.1 배경 및 목적
본 프로젝트는 **소상공인시장진흥공단 상가(상권)정보 데이터(2026년 6월 기준)**를 활용하여, 부산광역시에 위치한 2,780개 편의점의 위치 및 상세 정보를 지도 위에 시각화하고 검색할 수 있는 모바일 반응형 웹 서비스를 구축하는 것을 목적으로 합니다.
API 키 발급이나 유료 비용 발생 없이 완전 무료 오픈소스 지도(OpenStreetMap + Leaflet)를 활용하여 정적 웹 호스팅 환경에서도 독립적으로 서비스될 수 있도록 설계합니다.

### 1.2 핵심 목표
1. **완전 무료 오픈 지도 솔루션**: OpenStreetMap과 Leaflet.js를 결합하여 별도의 상용 API 키 등록 없이 영구 무료 운영.
2. **고성능 대용량 마커 렌더링**: 부산 전역 2,780개 지점을 지연 없이 부드럽게 탐색할 수 있도록 마커 클러스터링(Marker Clustering) 도입.
3. **직관적인 다차원 필터링 및 검색**:
   - 부산시 16개 구·군별 지역 필터
   - 브랜드별(CU, GS25, 세븐일레븐, 이마트24 등) 원클릭 토글 필터
   - 점포명 및 도로명 실시간 텍스트 검색
4. **모바일 퍼스트(Mobile-First) 반응형 UX**:
   - 모바일 환경: 지도 중심 풀스크린 + 상단 검색창 + 하단 슬라이딩 바텀 시트(Bottom Sheet)
   - 데스크톱 환경: 좌측 검색/필터/목록 사이드패널 + 우측 넓은 지도 화면

## 3. 핵심 기능 요구사항 (Functional Requirements)

### 3.1 지도 표시 및 마커 인터랙션 (Map & Markers)
- **무료 지도 타일 연동**: OpenStreetMap 표준 타일(`https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png`)
- **초기 중심 좌표**: 부산 중심부 (위도 `35.1796`, 경도 `129.0756`, 줌레벨 `11~12`)
- **마커 클러스터링**:
  - 축소 뷰에서는 밀집된 편의점을 그룹화하여 숫자 배지로 표시
  - 클러스터 클릭 시 해당 영역으로 부드럽게 확대(Spiderfy 기능 지원)
- **브랜드별 커스텀 마커 핀**:
  - 마커 색상 또는 로고 뱃지로 브랜드(CU, GS25, 세븐일레븐, 이마트24 등)를 즉각 시각적 구분
- **상세 팝업 (Popup) / 바텀시트 연동**:
  - 마커 터치/클릭 시 상호명, 지점명, 브랜드 배지, 도로명주소, 지번주소 표출
  - 외부 길찾기 연동 버튼 (네이버 지도, 카카오맵, 티맵 검색 링크)

### 3.2 검색 및 복합 필터 (Filter & Search)
1. **지역(시·군·구) 필터**:
   - `전체 구·군` 및 16개 구/군(부산진구, 해운대구 등) 드롭다운 셀렉트
   - 구 선택 시 해당 행정구역 중심부로 지도 자동 이동(Pan to) 및 줌
2. **브랜드 다중/단일 선택 칩 필터**:
   - `전체`, `CU`, `GS25`, `세븐일레븐`, `이마트24`, `기타`
   - 클릭 토글 방식으로 직관적인 On/Off 지원
3. **통합 키워드 검색**:
   - 검색창 입력 시 상호명, 지점명, 도로명 주소를 실시간 검색 (디바운스 200ms 적용)
4. **필터 초기화 버튼**:
   - 원클릭으로 모든 필터를 기본 상태(전체)로 리셋

### 3.3 사용자 편의 기능 (Utilities)
- **현재 위치(GPS) 찾기**:
  - Geolocation API를 사용하여 내 현재 위치로 지도 이동 및 "내 위치" 핀 표시
  - 반경 내 가장 가까운 편의점 탐색 지원
- **실시간 결과 통계 카운터**:
  - 현재 필터링된 점포 수 실시간 표출 (예: `"검색 결과 142개 점포"`)
- **점포 목록 뷰 (List View)**:
  - 검색된 편의점 목록을 카드 형태로 열람
  - 목록의 항목 클릭 시 지도 상 해당 마커로 자동 이동 및 팝업 오픈

## 4. UI/UX 및 반응형 디자인 (Responsive UI/UX)

### 4.1 뷰포트별 레이아웃

#### A. 모바일 뷰 (`< 768px`)
- **화면 구성**:
  - 상단: 고정 플로팅 검색바 및 구/군 셀렉터, 브랜드 칩 가로 스크롤 영역
  - 중앙: 풀스크린 지도 뷰
  - 우측 하단: "내 위치 찾기" 및 "지도 확대/축소" 플로팅 액션 버튼(FAB)
  - 하단: 드래그 가능한 접이식 바텀 시트(Bottom Sheet)
    - 평상시: 핸들바 + 검색 결과 개수 요약
    - 위로 당겼을 때: 점포 상세 카드 목록 스크롤

#### B. 데스크톱 뷰 (`>= 768px`)
- **화면 구성**:
  - 좌측 사이드바 (너비 약 380px ~ 420px):
    - 헤더 (서비스 타이틀 & 뱃지)
    - 검색창 및 구/군 필터
    - 브랜드 선택 버튼 그리드
    - 필터 결과 점포 목록 (무한 스크롤 또는 페이징)
  - 우측 메인 영역:
    - 전체 화면 반응형 지도

### 4.2 디자인 시스템
- **컬러 팔레트**:
  - Primary: `#2563EB` (모던 블루)
  - Background: `#F8FAFC` (슬레이트 화이트)
  - Card/Surface: `#FFFFFF` (클린 화이트)
  - Text: `#0F172A` (진회색 본문), `#64748B` (서브 텍스트)
- **타이포그래피**: 시스템 기본 폰트 스택 (Pretendard, Apple SD Gothic Neo, Malgun Gothic)

## 5. 기술 스택 및 아키텍처 (Tech Stack & Architecture)

### 5.1 기술 스택
- **Core**: HTML5, CSS3, Modern JavaScript (ES6+, No framework dependency)
- **Map Engine**: [Leaflet.js](https://leafletjs.com/) v1.9+ (오픈소스 경량 지도 라이브러리)
- **Clustering**: [Leaflet.markercluster](https://github.com/Leaflet/Leaflet.markercluster) v1.5+
- **Map Tile**: OpenStreetMap (OSM) Tile Server
- **UI Styling**: Tailwind CSS (CDN 방식 적용으로 가볍고 유지보수 용이)
- **Data Pipeline**: Python 전처리 스크립트를 통해 원본 CSV(1.3MB)를 경량화된 `stores.json`(약 400KB 이하)으로 변환

### 5.2 프로젝트 디렉토리 구조
```
data/
├── web/
│   ├── PRD.md                     # 본 제품 기획서
│   ├── index.html                 # 반응형 메인 웹 애플리케이션
│   ├── css/
│   │   └── style.css              # 커스텀 스타일 및 애니메이션
│   ├── js/
│   │   ├── app.js                 # 메인 애플리케이션 진입점 및 이벤트 제어
│   │   ├── map.js                 # Leaflet 지도 초기화, 클러스터링, 마커 관리
│   │   └── filter.js              # 지역/브랜드/키워드 필터링 엔진
│   └── data/
│       └── stores.json            # 최적화된 편의점 데이터셋
├── 소상공인시장진흥공단_상가(상권)정보_부산_편의점_202606.csv
└── convert_to_json.py             # CSV -> JSON 경량화 변환 스크립트
```
